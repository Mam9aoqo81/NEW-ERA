# مراجعة قبول KnowLM 0.9

## الحكم

**لا يستوفي التطبيق كل شروط المواصفات الأصلية، وليس جاهزًا للإطلاق العام.** هو نسخة أولية عاملة لجزء من مساحة الدراسة الخاصة. نجاح الاختبارات لا يعني اكتمال الخصائص أو صحة كل إجابة تربويًا.

مرجع النطاق: [مصفوفة المتطلبات](REQUIREMENTS.md). تمت مراجعة الفرع `arena/9ab35512-new-era` عند commit `626a193` وإعادة تشغيل الاختبارات محليًا. هذا التقرير لا يمثل تدقيق أمن مستقلًا أو اختبار إنتاج أو اختبار كل ملف محتمل.

## ما تغطيه الاختبارات

- تسجيل الحساب والدخول والدفاتر الخاصة والتحقق من ملكية المصادر والمهام والمخرجات.
- إضافة نص، ومعالجة PDF نصي وDOCX في العامل، وأخطاء الملفات وحدود الاستخراج وإعادة محاولة المهام.
- اختيار مصادر السؤال، الاستشهادات المحمية، الرفض عند غياب الدليل في الحالات المختبرة، وحفظ سجل المحادثة وإعادة تحميله.
- روابط YouTube **مع نص موقّت مرفق يدويًا**، وفتح مراجع التوقيت وحفظها؛ هذا ليس اختبار جلب الفيديو الحي أو مطابقة النص للفيديو.
- بطاقات اقتباسية ويدوية، تحرير وحذف منطقي، جدولة SM-2 variant وتعارض الإصدارات ومنع تكرار الحفظ.
- اختبارات بتصحيح خادمي ونتائج محفوظة، ومخرجات اقتباسية، وخرائط احتواء المصادر مع تحديد العقد والطي والتوسيع وفتح المرجع.
- تدفقات المتصفح الأربعة: نص/PDF وسؤال موثّق؛ YouTube بالنص المرفق؛ أدوات الدراسة والخرائط؛ Word بمراجع فقرات. الهاتف هنا محاكاة مقاس Chromium، وليس اختبار جهاز iPhone/Android فعلي.

## مقارنة القبول بالمواصفات

| المجال | النتيجة | الفجوة |
|---|---|---|
| واجهة عربية RTL وحسابات ودفاتر خاصة | موجودة ومختبرة ضمن النطاق الحالي | Safari وأجهزة فعلية وإتاحة شاملة وإدارة حسابات إنتاجية |
| PDF وWord ومراجع دقيقة | جزئي | PDF نصي وDOCX متن/جداول؛ لا OCR، ولا تطابق صفحات Word، ولا عارض أصل PDF بإحداثيات |
| روابط YouTube | **قبول حي غير مجتاز** | الجلب العام غير متحقق منه بسبب قيود الشبكة؛ المعاينة تعطل الجلب التلقائي. يلزم اختبار فيديوهات عربية وإنجليزية مسموحة في نشر مناسب |
| الصوت وروابط الويب وGoogle Docs | غير منفذة | لا STT ولا جلب ويب معزول ولا ربط Google Docs |
| RAG دلالي وإجابات AI من المصادر فقط | جزئي وغير مثبت إنتاجيًا | البحث BM25/تشابه حرفي لا embeddings. مزود LLM اختياري واختباراته بمحاكاة؛ التحقق من وجود الاقتباس لا يثبت استلزامه لكل ادعاء |
| بطاقات واختبارات ومخرجات دراسة | موجودة بنطاق اقتباسي | حذف كلمة حرفيًا ومشتتات من البطاقات وأسئلة عامة للمقاطع؛ ليس توليدًا تربويًا دلاليًا متكاملًا، ولا تقييم جودة مستقل |
| تكرار متباعد وخرائط ذهنية | جزئي | SM-2 variant دون إشعارات؛ خريطة مصدر/مقطع دون علاقات مفاهيم مستنتجة أو تحرير حر |
| المجتمع والمشاركة والتصنيف وKnowers | غير منفذة | لا موجز UGC أو نشر اختياري أو متابعة وتعليقات وإبلاغ وحظر أو تصنيف مناهج وملفات اجتماعية |
| دفاتر جماعية وغرفة AI وفحص حقائق | غير منفذة | لا عضوية وتعاون وتزامن أو ختم جودة موثوق |
| بودكاست وصوت ولهجات ومقاطعة ميكروفون | غير منفذة | لا مسار صوتي متكامل أو Realtime؛ لا يكفي توليد ملف صوت منفصل لتحقيق المتطلب |
| Canvas وقلم وOCR خط اليد وفيديو تعليمي وغرف Pomodoro صوت/فيديو | غير منفذة | تحتاج مسارات منتج واتصال ومعالجة وصلاحيات فعلية |
| تطبيقات هاتف أصلية | غير منفذة | الموجود ويب متجاوب فقط |
| جاهزية النشر والأمان والخصوصية | غير مكتملة | لا اعتماد إنتاجي للحصص وrate limiting والحذف والاحتفاظ والنسخ الاحتياطية واستعادة الحساب وحماية القُصّر؛ PostgreSQL والحمل لم يُختبرا فعليًا |

## بوابات القبول التالية

1. إغلاق قبول YouTube الحي في بيئة تسمح بالاتصال، مع مصادر مرخّصة واختبار فشل واضح؛ لا نعتمد النص اليدوي بديلًا لإثبات الجلب.
2. اختبار مزود LLM وembeddings فعليين، وتقييم مستقل للاسترجاع واستلزام الادعاءات ورفض الأسئلة وحقن التعليمات. البيانات الاصطناعية الصغيرة ليست دليل جودة عام.
3. إكمال باقي خصائص المنتج الموضحة أعلاه مع اختبارات قبول مستقلة لكل مجال، لا مجرد إضافة أزرار.
4. معالجة بوابات الأمان والاحتفاظ والخصوصية والإشراف، واختبار PostgreSQL والنسخ الاحتياطية والحمل قبل الإطلاق.

**قرار المراجعة:** يصلح طلب الدمج لمراجعة نواة أولية مع حدود معلنة؛ لا يصح وصفه بتنفيذ كامل للبرومبت أو اعتماد إطلاق عام.
