# لوحة القلم والملاحظات الخاصة

داخل كل دفتر افتح «لوحة المذاكرة بالقلم والملاحظات». الرسم SVG عبر Pointer Events يدعم الفأرة والقلم واللمس، واختيار اللون والسمك والتراجع عن آخر خط. الملاحظات النصية بديل متاح بلوحة المفاتيح، وليست تحويلًا آليًا للخط. لا يوجد تعرف على خط اليد أو رد AI من الرسم أو اختبار جهاز قلم فعلي حتى الآن.

## الحفظ والخصوصية

- حفظ صريح بالخادم، لا localStorage ولا نشر عام ولا إرسال إلى مزود خارجي. لوحة واحدة لكل مستخدم ودفتر. حتى مالك الدفتر لا يرى لوحة عضو آخر. القارئ يستطيع الكتابة في لوحته الشخصية فقط دون تعديل المصادر المشتركة.
- احفظ قبل تبديل الدفتر أو تسجيل الخروج أو التنقل داخل التطبيق؛ تحذير إغلاق المتصفح عند وجود تغييرات ليس ضمانًا (خصوصًا الهواتف). التعديلات غير المحفوظة لا تُستعاد بعد المغادرة.
- `version` يمنع تبويبًا قديمًا من الكتابة فوق حفظ أحدث؛ 409 يحتفظ بمسودة الواجهة مع رسالة خطأ. لا دمج تلقائي ولا عمل دون اتصال. احتفظ بالملاحظات قبل إعادة التحميل عند تعارض.
- حتى 200 خط، 1000 نقطة لكل خط، 10000 حرف ملاحظات و20 مرجعًا. إحداثيات مقيدة بمساحة 1000×600، اللون hex فقط، ولا SVG/HTML يقدمه المستخدم.
- افتح مرجعًا من إجابة ثم أغلق قارئ المرجع واضغط «ربط آخر مرجع فتحته باللوحة». الخادم يقبل معرف مقطع من الدفتر نفسه فقط، ويولد المرجع من المصدر. الملاحظة ليست اقتباسًا موثقًا تلقائيًا؛ المرجع لا يثبت صحة محتواها. الربط لا يرسل الرسم للسؤال.
- الحذف الكامل يتطلب تأكيدًا ثم حفظًا. حذف الدفتر يمحو كل لوحاته؛ حذف الحساب يمحو لوحاته حتى في دفاتر الآخرين. إزالة العضوية تمنع القراءة والحفظ التاليين، لكن اللوحة تبقى حتى حذف الحساب/الدفتر وقد تعود عند استعادة العضوية. قيود النسخ الاحتياطية في PRIVACY.md تنطبق.

## API والترحيل

جلسة إلزامية وصلاحية قراءة الدفتر لكل طلب:

- `GET /v1/notebooks/{id}/canvas` يرجع version=0 للوحة الجديدة، مع `Cache-Control: no-store`.
- `PUT` بنفس المسار: `{version, strokes: [{color,width,points:[{x,y}]}], notes, chunk_ids}`. الاستجابة تحمل النسخة التالية ومراجع يولدها الخادم. لا يقبل حقولًا إضافية أو قيمًا غير محدودة.

قبل تشغيل الإصدار الجديد: أوقف API ثم `alembic upgrade head` وأعد تشغيله. الترحيل `4b45d29d2a42` يضيف ink_boards؛ downgrade يمحو اللوحات فقط. الكتابة تقفل صف الدفتر وتتحقق من الصلاحية والنسخة والمراجع. لم تختبر تحت حمل PostgreSQL.

## التحقق

3 اختبارات Backend للعزل والتحقق من المراجع والتعارض وحذف الدفتر/الحساب وسحب العضوية. اختبارا React للحفظ المتفائل والاحتفاظ بالملاحظات عند التعارض. اختبار متصفح على مقاسي الكمبيوتر والهاتف يرسم بأحداث pointer فعلية ويحفظ الخط والملاحظات ويستعيدهما بعد reload؛ محاكاة المقاس ليست شهادة توافق مع قلم جهاز حقيقي. الجولة الكاملة قبل اختبار العضوية الإضافي: 218 Backend ناجحًا وواحد متخطى، 52 Frontend، 24 متصفحًا، وبناء الإنتاج والترحيل ناجحان. اختبار العضوية الإضافي ناجح ضمن إعادة اختبارات اللوحة الثلاثة.
