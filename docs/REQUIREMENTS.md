# KnowLM — تتبّع المواصفات الأصلية

هذه المصفوفة هي مرجع نطاق المنتج، لا قائمة ادعاءات تسويقية. «موجود تجريبيًا» لا يعني جاهزية إنتاجية. لا نعتبر خاصية منتهية لمجرد وجود زر أو موصّل غير مختبر حيًا.

## بوابات الجاهزية قبل الإطلاق العام

- حماية XSS/CSRF مناسبة لتصميم المصادقة، HTTPS وCSP وإدارة أسرار.
- حدود معدل وحصص عددية موجودة تجريبيًا؛ ما زالت حصص bytes والتكلفة والتزامن العالمي وسياسات الاحتفاظ والنسخ الاحتياطية قيد التنفيذ.
- حماية قُصّر، موافقة على إرسال المصادر لمزوّد خارجي، حقوق نشر وإشراف على UGC.
- تشغيل PostgreSQL فعليًا واختبار ترقيات البيانات تحت حمل؛ الحالي مختبر محليًا على SQLite.
- تقييم RAG بمصادر واقعية مرخّصة ومجموعة مستقلة، لا الاكتفاء بالـ22 سؤالًا المصطنعًا.
- قياس التأخير والتكلفة وإتاحة الاستخدام وإمكانية الوصول.

## ترتيب الدفعات القادمة

1. **إغلاق قبول YouTube الحي** في نشر مسموح، مع إبقاء الاستيراد الموقّت بديلًا صريحًا.
2. تقييم جودة البطاقات والاختبارات وإشعارات المراجعة وتحسين التوليد.
3. استرجاع دلالي ومخرجات الدراسة، ثم Web/صوت وOCR وتحسين تغطية DOCX.
4. المجتمع والنشر الاختياري والدفاتر الجماعية مع ضوابط الخصوصية والإشراف.
5. البودكاست بالعربية والإنجليزية ثم اللهجات، فالمقاطعة الصوتية والغرف والابتكارات البصرية والـCanvas.

لا يمكن إعلان استيفاء جميع المواصفات قبل اجتياز شروط القبول في هذه المصفوفة؛ التنفيذ الحالي نواة متنامية وليست المنتج الكامل.
